# SENTINEL SOC — AI Services & Assistants Guide
**Last Updated:** November 16, 2026 (Release 2 Verification Gap Closure)

## 1. Free-Tier Architecture & Safety Principles

Sentinel SOC provides two dedicated AI assistants designed specifically for security operations:
1. **Advisory AI Security Analyst:** Synthesizes authorized security events, threat intelligence indicators, and attack correlation chains into grounded investigation briefings.
2. **Sentinel AI Helpdesk:** Provides troubleshooting, setup diagnostics, and documentation assistance for administrators and analysts.

### Core Free-Tier Principles:
- **No Mandatory Paid Subscriptions:** Operates seamlessly via Google Gemini API's eligible free tier, local open-source LLMs (Ollama / Llama-3 / Mistral), or a built-in deterministic heuristic fallback.
- **Configurable Provider & Models:** Provider (`gemini`, `ollama`, or `fallback`/`mock`) and model names are controlled via environment variables (`AI_PROVIDER`, `GEMINI_MODEL`, `OLLAMA_MODEL`, `GEMINI_API_KEY`).
- **Graceful Quota Handling:** If a rate limit (HTTP 429) occurs, Sentinel SOC never attempts to auto-upgrade to paid tiers. It renders a prominent user banner:
  > *"AI quota temporarily unavailable. Core Sentinel SOC functionality is still operational."*
- **Tenant Isolation:** All prompts are strictly scoped to the user's authenticated organization tenant. Cross-tenant data leakage is prevented at the query layer.

## 2. Gemini API Free-Tier Configuration Guide

To enable live Gemini API requests at zero financial cost:

### Step 1: Obtain a Free Gemini API Key
1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your standard Google account.
3. Click **"Get API key"** and create a free API key.
4. Verify that the project is in the **Free Tier** (no billing account required for basic prototyping/testing).

### Step 2: Configure Environment Variables
Create or update your `.env` file in the project root:
```env
AI_PROVIDER=gemini
GEMINI_API_KEY=AIzaSy...your-free-key-here...
GEMINI_MODEL=gemini-1.5-flash
AI_REQUEST_TIMEOUT=20
```

### Step 3: Quota Awareness & Backoff
- The free tier of Gemini 1.5 Flash offers **15 Requests Per Minute (RPM)**, **1,500 Requests Per Day (RPD)**, and **1 million Tokens Per Minute (TPM)** at $0 cost.
- Sentinel SOC implements automatic 429 backoff. If quota limits are reached, requests automatically degrade to the deterministic heuristic fallback provider without interrupting core SOC telemetry or alerting.

## 3. Advisory AI Security Analyst

### 3.1 Advisory-Only / Human-in-the-Loop Constraint
The AI Security Analyst is strictly advisory. It **cannot** automatically quarantine endpoints, push router firewall drop rules, or revoke IAM credentials without explicit human confirmation and action.

### 3.2 Five-Part Structured Evidence Breakdown
Every investigation briefing generated by `/api/v1/ai-analyst/investigate` follows a rigid 5-part structure:
1. **Observable Facts:** Direct telemetry observed in system/network event logs (timestamps, source/destination IPs, usernames, port numbers, process executions).
2. **Corroborated Threat Intelligence:** Third-party enrichment from AbuseIPDB, GreyNoise, AlienVault OTX, or Spamhaus, explicitly citing confidence scores and attribution.
3. **Security Explanations & Hypotheses:** Analysis of adversary tactics, intent, and stage in the cyber kill chain (e.g. initial access, credential stuffing, lateral movement, C2 beaconing).
4. **Actionable Recommendations:** Immediate containment steps, eradication guidance, and log search queries for the security analyst.
5. **Unknowns & Visibility Gaps:** Explicit enumeration of unobserved telemetry (e.g. host memory dump unavailable, packet capture unconfigured on subnet, encrypted payload uninspected).

### 3.3 MITRE ATT&CK Mapping
The analyst correlates detected patterns with MITRE ATT&CK Enterprise Matrix tactics and techniques (e.g. *T1110.004 Credential Stuffing*, *T1046 Network Service Discovery*, *T1071 Application Layer Protocol C2*, *T1078 Valid Accounts*).

## 4. Sentinel AI Helpdesk & RAG Architecture

The AI Helpdesk (`/ai-helpdesk` and `/api/v1/ai-helpdesk/chat`) assists operators with installation, sensor enrollment, detection tuning, and system diagnostics.

### 4.1 Diagnostic Redaction & Credential Scrubbing
Before any user log, diagnostic output, or system error is submitted to the LLM, it passes through Sentinel's sanitization pipeline (`backend/app/core/ip_utils.py` and `backend/app/core/ai/redaction.py`):
- JWT Bearer tokens $\rightarrow$ `[REDACTED_JWT_TOKEN]`
- AWS Access Keys (`AKIA...`) $\rightarrow$ `[REDACTED_AWS_ACCESS_KEY]`
- AWS Secret Keys $\rightarrow$ `[REDACTED_AWS_SECRET_KEY]`
- Passwords and API secrets $\rightarrow$ `[REDACTED_CREDENTIAL]`
- SSH / RSA Private Keys $\rightarrow$ `[REDACTED_PRIVATE_KEY]`

### 4.2 Documentation Grounding (RAG)
The Helpdesk indexes Sentinel SOC's Markdown documentation (`docs/*.md`) to deliver answers grounded in verified local architecture rather than hallucinated procedures.

### 4.3 Strict Eight-Part Troubleshooting Format
When answering troubleshooting questions or analyzing error messages, the Helpdesk formats responses using eight standardized sections:
1. **Issue Identification & Summary:** Plain-language summary of the reported failure.
2. **Probable Root Cause:** Technical explanation of the failure mechanism.
3. **Affected Subsystem:** Specific Sentinel component (e.g., Sensor Ingestion, Correlation Engine, Threat Intel Adapter).
4. **Immediate Step-by-Step Fix:** Actionable remediation instructions.
5. **Configuration Verification Command:** Shell or curl command to verify resolution.
6. **Rollback / Recovery Option:** Steps to revert changes safely if the fix fails.
7. **Related Documentation Links:** Exact references to `docs/` files.
8. **Known Caveats & Free-Tier Limitations:** Notes on rate limits or constraints.

## 5. Configuration & Environment Variables Reference

| Variable | Description | Default | Free-Tier Notes |
| :--- | :--- | :--- | :--- |
| `AI_PROVIDER` | AI engine (`gemini`, `ollama`, or `fallback`) | `gemini` | Falls back to `fallback` if key is unset. |
| `GEMINI_API_KEY` | Google Gemini API key | `""` (Unset) | Use free tier from Google AI Studio. |
| `GEMINI_MODEL` | Gemini model name | `gemini-1.5-flash` | Free tier model eligible. |
| `OLLAMA_BASE_URL`| Local Ollama server address | `http://localhost:11434` | Fully free, 100% offline local model. |
| `OLLAMA_MODEL` | Local model name | `llama3` | Requires local GPU/CPU hardware. |
| `AI_REQUEST_TIMEOUT` | Maximum execution timeout (seconds) | `30` | Prevents UI hanging on slow queries. |
